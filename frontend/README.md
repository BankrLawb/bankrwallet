# BankrWallet Frontend

Marketing site and documentation for BankrWallet.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Pages

| Route | Description |
|-------|-------------|
| `/` | Landing page |
| `/docs` | Documentation overview |
| `/docs/how-it-works` | Command pipeline |
| `/docs/contracts` | Contract reference |
| `/docs/security` | Security model |
| `/docs/bot-integration` | Bot / @bankrbot integration |
| `/docs/deploy` | Foundry deploy guide |

## Stack

- Next.js 14 (App Router)
- Tailwind CSS
- Framer Motion
- Inter + Space Mono (Google Fonts)
